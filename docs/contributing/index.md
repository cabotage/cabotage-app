# Contributing to Cabotage

This section is for people working **on Cabotage itself** — changing its
application code, infrastructure tooling, CI, or this documentation site. If
you are instead deploying your own application onto a Cabotage platform, see
[Using Cabotage](../using/index.md). If you administer a Cabotage platform
for others, see the operator guides linked from the documentation home.

## Contribution policy

The authoritative contribution policy — how to pick up an issue, branch and
commit conventions, the pull request process, bug reports, and security
disclosure — lives in the repository root and is not duplicated here:

[CONTRIBUTING.md on GitHub](https://github.com/cabotage/cabotage-app/blob/main/CONTRIBUTING.md)

Read it before opening a pull request.

## What's in this section

- **[Local development](local-development.md)** — run the application stack
  with Docker Compose, manage Python dependencies with `uv`, install Git
  hooks, and run the checks and tests used by CI.
- **[Documentation](documentation.md)** — how this documentation site is
  built, how to preview changes locally, and how to add or edit pages.
