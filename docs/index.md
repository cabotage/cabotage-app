# Cabotage documentation

Cabotage builds, releases, and deploys applications on Kubernetes, with configuration in Consul, secrets in Vault, and end-to-end TLS.

## Using Cabotage

**Deploying your own applications on Cabotage? Start here.** These guides are for application developers and teams using an existing Cabotage platform. You do not need to work on Cabotage's codebase.

Start with [deploying your code](using/deploying.md), then define your [processes](using/processes.md), manage [configuration](using/configuration.md), and read [application logs](using/observing.md).

[Browse the user guides](using/index.md).

## Operating Cabotage

**Running the Cabotage platform for others?** These guides cover platform authentication, MFA rollout, network isolation, and Tailscale ingress. Organization admins deploying their team's applications should use the user guides above; these settings concern the platform itself.

[Browse the operator guides](operating/index.md).

## Contributing to Cabotage

**Working on Cabotage itself? Read here.** This section is for changing Cabotage's own code, tooling, or documentation — not for developing applications that run on Cabotage.

Start with [local development](contributing/local-development.md) or [writing documentation](contributing/documentation.md). The [contribution policy](https://github.com/cabotage/cabotage-app/blob/main/CONTRIBUTING.md) covers pull requests, reporting bugs, and security disclosures.

[Browse the contributor guides](contributing/index.md).
